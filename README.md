# FridgeMind — Deploy & Test on iPhone

## What You Need
- Your iPhone
- A computer (Mac or PC)  
- A free GitHub account (github.com)
- A free Vercel account (vercel.com)

---

## STEP 1: Create a GitHub Account (skip if you have one)
1. Go to https://github.com
2. Click "Sign up"
3. Use your email (kentaro@connecteris.com works fine)
4. Pick a username and password
5. Verify your email

## STEP 2: Upload This Project to GitHub
1. Log into GitHub
2. Click the green "New" button (top left) to create a new repository
3. Name it: fridgemind
4. Keep it Public (free)
5. Click "Create repository"
6. On the next page, click "uploading an existing file" link
7. Drag and drop ALL the files/folders from this project into the upload area
8. Click "Commit changes"

## STEP 3: Deploy on Vercel (Free)
1. Go to https://vercel.com
2. Click "Sign Up" → choose "Continue with GitHub"
3. Authorize Vercel to access your GitHub
4. Click "Add New Project"
5. Find your fridgemind repository and click "Import"
6. Leave all settings as default (Vercel auto-detects Vite)
7. Click "Deploy"
8. Wait 30-60 seconds
9. You will get a live URL like: https://fridgemind-xxxx.vercel.app

## STEP 4: Test on Your iPhone
1. Open Safari on your iPhone (MUST be Safari, not Chrome)
2. Go to your Vercel URL
3. The app loads and looks like a real app
4. To add to home screen:
   - Tap the Share button (box with arrow at bottom of Safari)
   - Scroll down and tap "Add to Home Screen"
   - Name it "FridgeMind"
   - Tap "Add"
5. Open it from your home screen - runs fullscreen, no browser bars

## STEP 5: Custom Domain (Optional)
Buy fridgemind.app or similar ($10-15/year), then:
1. Vercel dashboard → project → Settings → Domains
2. Add your domain
3. Update DNS (Vercel shows you exactly how)
